# Intranet

O patrimônio fica em [`apps/patrimonio`](apps/patrimonio). O desenho fechado está em [`docs/intranet.md`](docs/intranet.md). O plano de implementação está em [`docs/superpowers/plans/2026-11-27-intranet.md`](docs/superpowers/plans/2026-11-27-intranet.md).

Para desenvolver o patrimônio:

```bash
cd apps/patrimonio
bun install
bun run dev
```

A instalação avulsa continua por `./install.sh` na raiz deste repositório.
